# Push notifications
- **What:** Web Push (works in Chrome and Edge on Android and desktop, Firefox, installed web apps on iPhone with iOS 16.4+, and the Google Play wrapper). No third-party push service account is needed: the push Worker talks to each browser's own push service.
- **Which events:** replies to your confessions, Whispers, private messages, and (off by default) Echoes. Each has a switch in Settings > Notifications. **Not** sent: reactions, "come back" reminders, streak reminders, anything promotional.
- **What it says:** only that something happened ("Someone replied to your confession."), with a link. Never the text, never who. Notifications about the same thing are combined, at most one per 10 minutes.
- **How it works:** database triggers queue a notification when a reply, Whisper, message or Echo arrives, only for people who have a subscribed device and the kind switched on, and never from someone they blocked. The push Worker runs every minute, claims a batch, encrypts each message for the device (RFC 8291) and signs the request (VAPID, RFC 8292). Dead subscriptions (404 or 410 from the push service) are removed; temporary failures are retried up to 3 times; old items are pruned after 2 days.
- **Privacy:** a device's push address is private data stored against the identity, deleted when the person turns notifications off, purges the device, or deletes the identity.
- **Setup:** `node cloudflare/workers/push/generate-vapid.mjs`; put the public key in `wrangler.toml` and in the web app as `NEXT_PUBLIC_VAPID_PUBLIC_KEY`; `wrangler secret put VAPID_PRIVATE_KEY` and `SUPABASE_SERVICE_KEY`; set `VAPID_SUBJECT` to a contact address; `wrangler deploy`; run `0019_push.sql`.
- **Tested:** SQL suite (queueing rules, coalescing, preferences, blocking, batch claiming, purge); Worker end to end, where the encrypted output is decrypted by an independent library (`http_ece`) and the VAPID signature is verified; service worker logic (links, off-site links refused). **Not tested:** a real push service (Google, Mozilla, Apple) or a real browser prompt.
